تحديث واتساب المستقل للفروع — MOOD / Alpha
================================================

ما تم تعديله:
1) إعدادات واتساب أصبحت محفوظة في branch_settings حسب branch_id.
2) لكل فرع UltraMsg Instance ID وToken وقوالب وتفعيلات مستقلة.
3) صفحة الإعدادات تعرض وتحفظ إعدادات الفرع المختار فقط.
4) الطلب يحمل branch_id عند إرسال الرسائل والفاتورة PDF.
5) Edge Function send-ultramsg تقرأ حساب UltraMsg الخاص بالفرع.
6) رسائل الجاهزية والاستلام والمندوب تحترم تفعيل/تعطيل كل فرع.
7) سجل واتساب يستمر في حفظ branch_id.
8) يوجد fallback للإعدادات القديمة ULTRAMSG_INSTANCE_ID وULTRAMSG_TOKEN لمنع توقف النظام أثناء الانتقال.

خطوات التطبيق في Supabase:
1) شغّل migration:
   supabase/migrations/20260731_whatsapp_per_branch.sql
2) أعد نشر Edge Function:
   supabase functions deploy send-ultramsg
3) من المنظومة اختر فرع MOOD ثم الإعدادات > واتساب وأدخل Instance/Token واحفظ.
4) اختر Alpha وكرر الخطوة بحسابه المستقل.
5) اختبر طلبًا تجريبيًا من كل فرع.

ملاحظة الفحص:
- تم فحص التعديلات ومسارات الاستدعاء يدويًا.
- تعذر تشغيل build كامل داخل بيئة العمل لأن الحزمة الأصلية تحتوي ملفًا باسم تالف داخل src/components
  ولأن بعض حزم npm غير متاحة من سجل البيئة. لم يتم حذف الملف أو تغيير أي جزء غير متعلق بواتساب.
