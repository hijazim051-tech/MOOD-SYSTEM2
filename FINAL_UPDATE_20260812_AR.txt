MOOD - التعديل النهائي 2026-08-12

التعديلات المطبقة:

1) الورد الصناعي / البوكسات
- فئات الورد الصناعي لم تعد تظهر لموظف التغليف.
- الورد الصناعي والتغليف الخاص بالبوكسات يعامل كمصروف تشغيلي.
- البوكس نفسه يبقى منتج مخزون، وسعر البيع هو السعر النهائي شامل الورد والتغليف بالتقدير.
- فئات الاستخدام القديمة بقيت في قاعدة البيانات فقط للحفاظ على السجلات القديمة، لكنها غير مستخدمة في التغليف والتنبيهات.

2) تنبيهات المخزون
- المنتج لا يظهر كناقص ولا يرسل تنبيه إذا كان حد التنبيه = 0 أو غير محدد.
- التنبيه يعمل فقط عندما تحدد أنت حدًا أكبر من صفر.
- تم تطبيق ذلك على لوحة التحكم، إدارة المنتجات، واجهة التغليف، والتنبيهات العامة.
- لا توجد تنبيهات لفئات الورد الصناعي القديمة.

3) المشتريات
- واجهة جديدة حسب الأقسام.
- تختار القسم ثم نوع المنتج.
- تظهر كل التفاصيل/الألوان أمامك في جدول واحد.
- تكتب كمية كل لون وسعر الشراء والبيع ثم تضغط "تم".
- مثال الورد الطبيعي: قسم الورد الطبيعي -> جوري -> كل الألوان -> الكمية والسعر لكل لون.
- يوجد بحث سريع.
- إضافة منتج جديد غير موجود من داخل المشتريات.
- إضافة مورد سريع.
- تعديل فواتير المشتريات القديمة ما زال موجودًا.
- الدفع: كامل / جزئي / آجل، وكاش أو مصرف.

4) واتساب - إصلاح للمحلين
- Edge Function send-ultramsg أصبحت تقرأ whatsapp_instance و whatsapp_token حسب branch_id.
- لم يعد النظام يجبر كل الفروع على Instance واحدة من Secrets.
- في حال لم توجد إعدادات للفرع يوجد fallback إلى Secrets.
- إذا فشل تحميل إعدادات واتساب في المتصفح بسبب RLS/شبكة، لا تتوقف الرسالة؛ تستعمل آخر إعدادات محلية ويقوم Edge Function بحسم بيانات الربط.
- رسالة جاهز في واجهة التغليف أصبحت تحدث إعدادات الفرع قبل الإرسال.
- تمت إضافة migration لإنشاء bucket عام باسم invoices وسياسات رفع/قراءة ملفات PDF حتى يستطيع Evolution تنزيل ملف الفاتورة.

مهم بعد تركيب النسخة:

A) شغل SQL:
supabase/migrations/20260812_final_inventory_purchases_whatsapp.sql

B) انشر Edge Function الجديدة:
supabase functions deploy send-ultramsg

C) تأكد في إعدادات كل فرع داخل MOOD:
- WhatsApp Instance
- WhatsApp Token
يجب أن يكونا خاصين بذلك الفرع/الرقم.

D) يجب أن تكون جلسة Evolution نفسها Connected.
إذا كان حساب واتساب مقيدًا/محظورًا فلن تستطيع أي برمجة إرسال الرسائل حتى يرجع الحساب.

E) Build:
cd apps/client
npm run build

F) رفع:
git add .
git commit -m "Simplify purchases alerts and fix WhatsApp per branch"
git push origin main

مراجعة تقنية:
- تم فحص Syntax للملفات المعدلة بواسطة TypeScript transpiler ولم تظهر أخطاء parsing.
- تعذر تشغيل npm ci/build كامل داخل بيئة ChatGPT بسبب عدم توفر تنزيل dependencies؛ شغل npm run build على جهازك كاختبار TypeScript النهائي.
