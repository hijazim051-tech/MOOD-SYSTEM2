تم تنفيذ التعديلات السبعة المعتمدة:

1) تثبيت الهيدر أعلى الصفحة أثناء التمرير.
2) إعادة ترتيب واجهة موظف التغليف: تظهر قائمة الطلبات أولًا، وعند فتح الطلب تظهر بياناته وإنجازه من الداخل مع زر رجوع والتنقل بين بنود الطلب.
3) إصلاح صفحة الموظفين لتقرأ المستخدمين المسجلين من نفس مصدر صفحة المستخدمين وتفلترهم حسب الفرع.
4) المشتريات: عند اختيار مدفوع جزئيًا يظهر اختيار طريقة دفع الجزء المدفوع (كاش أو مصرف).
5) الباقة: اختيار إجباري بغلاف/بدون غلاف، وإذا كانت بغلاف يجب اختيار لون غلاف.
6) إنشاء صفحة مستقلة في القائمة باسم طلبات المندوبين، وإخفاء الطلبات الخارجة للتوصيل من صفحة طلبات المحل.
7) الحجز/طلب جديد: إلغاء إدخال بيانات المندوب وقت الحجز؛ الموجود فقط هل يوجد توصيل وهل قيمة التوصيل خالصة. اسم ورقم المندوب يدخلان من الطلبات عند استلمه المندوب.

ملاحظات الاختبار:
- تم إجراء فحص صياغة TypeScript/JSX على الملفات المعدلة ولم تظهر أخطاء صياغة.
- تعذر تشغيل npm install/build كاملًا داخل بيئة العمل لأن مرآة الحزم لم توفر zustand@5.0.14.
- شغّل محليًا داخل apps/client:
  npm install
  npm run build
