تم تنفيذ الدفعة المطلوبة على النسخة المرفوعة:
- صلاحيات الصفحات فتح/قفل لكل مستخدم.
- ربط القائمة الجانبية بالصلاحيات الفعلية.
- تنظيم الهيدر للهاتف.
- نظام عروض: باقة/بوكس/منتج مع مكونات وكميات.
- منع تسجيل الحضور والانصراف خارج نطاق GPS.
- جدول وصفحة مستقلة لمندوبي التوصيل + اقتراح اسم الكابتن.
- صفحة مسحوبات الموظفين وتسجيلها باسم المستخدم الحالي.
- جداول دوام وغياب ودالة توليد الغياب التلقائي.
- عرض الغياب والمسحوبات في صفحة الموظفين.
- تحسينات استجابة عامة للهاتف.

التحقق:
- تم فحص تركيب جميع ملفات TypeScript/TSX ولم تظهر أخطاء Syntax.
- تعذر تشغيل npm install داخل بيئة الإعداد بسبب عدم توفر حزمة zustand في مرآة npm الداخلية؛ لذلك يجب تشغيل npm run build عندك بعد تطبيق SQL.
