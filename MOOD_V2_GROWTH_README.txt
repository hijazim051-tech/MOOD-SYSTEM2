MOOD v2 - دفعة النمو والتحليلات

1) شغّل ملف SQL:
supabase/migrations/20260726_mood_v2_growth_automation.sql

2) شغّل الواجهة من apps/client:
npm install
npm run dev

الإضافات:
- مركز نمو وتحليلات موحد
- CRM مبني على العملاء والطلبات
- نقاط ولاء وحركات نقاط
- كوبونات
- مقارنة الفروع
- ملخص ساعات الحضور
- إعدادات رواتب
- قوالب واتساب
- جداول الملخصات ووقت عدم الإزعاج

مهم:
- الإرسال التلقائي الحقيقي عبر واتساب يحتاج WhatsApp Business API رسمي.
- إرسال الملخصات المجدولة يحتاج Supabase Cron/Edge Function بعد تحديد أوقات التشغيل.
