MOOD V3 — الدفعة الموحدة

تتضمن النسخة:
- عزل الفروع واختيار الفرع للمالك.
- ربط المستخدم والطلبات والتقارير بالفرع.
- لوحة التحكم الحالية المتقدمة مع مؤشرات التشغيل والمخزون والربح.
- التقارير المالية مع CSV وExcel متوافق وPDF عبر نافذة الطباعة.
- إعداد طباعة A4 للتقارير مع ملخص وبنود الطلبات.
- الصفحات السابقة: CRM، النمو والتحليلات، الإشعارات لكل مستخدم، واتساب اليدوي، الحضور، نقل المخزون، الموردون، المشتريات، المرتجعات.

مهم:
- Excel يُصدر بصيغة .xls المتوافقة مع Microsoft Excel بدون مكتبة خارجية.
- زر PDF يفتح معاينة الطباعة؛ اختر Save as PDF من الطابعة.
- WhatsApp Business API التلقائي يحتاج حساب Meta ومفتاح وصول ولا يعمل بمجرد كود الواجهة.
- يلزم اختبار البيانات الفعلية لأن أسماء/أنواع بعض أعمدة قاعدة البيانات تختلف بين النسخ القديمة.
